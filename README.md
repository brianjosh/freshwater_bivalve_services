# freshwater_bivalve_services

This repository contains the data and code necessary to carry out the analyses described in:

Zieritz, A. et al. (2025) "A global meta-analysis of ecological functions and regulating ecosystem services of freshwater bivalves", Limnology and Oceanography. 

Data collected and prepared by all co-authors; code prepared by Joshua Brian and Ana Sofia Vaz. Questions should be directed to jshbrian@gmail.com
